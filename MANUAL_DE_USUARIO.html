📖 Introducción

Bienvenido al sistema de gestión integral Ardyn Labs

🎯 ¿Qué es Ardyn Labs?

Ardyn Labs es un sistema integral de gestión empresarial diseñado para optimizar todas las operaciones de tu negocio. Desde el registro de ventas y egresos hasta el análisis avanzado de datos, Ardyn Labs centraliza toda la información en una plataforma moderna, intuitiva y potente.

📊 Dashboard Principal

Centro de operaciones diarias

🎛️ Vista General del Dashboard

El dashboard es el corazón del sistema donde realizarás la mayoría de las operaciones diarias. Está dividido en dos secciones principales: VENTAS y EGRESOS.

📋 Componentes del Dashboard

  • Pestañas VENTAS/EGRESOS: Alterna entre el registro de ventas y gastos
  • Formulario de Registro: Panel izquierdo para ingresar nuevas transacciones
  • Historial Reciente: Panel derecho con las últimas transacciones registradas
  • Botón Importar Excel: Permite cargar múltiples registros desde un archivo Excel
💡
Tip: Usa las pestañas para cambiar rápidamente entre ventas y egresos sin perder tu progreso.

💰 Gestión de Ventas

Registra y administra todas tus ventas

📝 Registrar una Venta

  1. Seleccionar la pestaña VENTAS
    En el dashboard principal, asegúrate de estar en la pestaña "VENTAS".
  2. Completar la Fecha
    El campo de fecha se completa automáticamente con la fecha actual. Puedes modificarla si necesitas registrar una venta de otro día.
  3. Seleccionar Cliente
    Haz clic en el campo "CLIENTE" y comienza a escribir el nombre o teléfono. El sistema mostrará sugerencias automáticamente. Selecciona el cliente correcto de la lista.
  4. Ingresar el Importe
    Escribe el monto total de la venta en el campo "IMPORTE ($)".
  5. Seleccionar Método de Pago
    Elige entre: Efectivo, Transferencia, Tarjeta de Débito, Tarjeta de Crédito, o Cuenta Corriente.
  6. Agregar Conceptos (Opcional)
    Puedes detallar los productos o servicios vendidos en el campo "CONCEPTOS".
  7. Guardar la Venta
    Haz clic en el botón "💰 REGISTRAR VENTA" para guardar la transacción.
✅
Confirmación: Verás un mensaje de confirmación y la venta aparecerá inmediatamente en el historial.

💳 Métodos de Pago Disponibles

Método Descripción Uso Recomendado
💵 Efectivo Pago en dinero físico Transacciones en el local
🏦 Transferencia Transferencia bancaria Pagos remotos o grandes montos
💳 Tarjeta Débito Pago con tarjeta de débito Transacciones con POS
💳 Tarjeta Crédito Pago con tarjeta de crédito Ventas con financiación
📝 Cuenta Corriente Compra a crédito Clientes con línea de crédito
⚠️
Importante: Si seleccionas "Cuenta Corriente", la deuda del cliente se actualizará automáticamente y recibirá una notificación por WhatsApp.

📊 Importar Ventas desde Excel

Para registrar múltiples ventas de forma masiva:

  1. Hacer clic en "IMPORTAR EXCEL"
    Se abrirá el panel de importación.
  2. Descargar la plantilla
    Haz clic en "📥 DESCARGAR PLANTILLA" para obtener el formato correcto.
  3. Completar la plantilla
    Llena el archivo Excel con tus datos siguiendo el formato de la plantilla.
  4. Subir el archivo
    Arrastra el archivo a la zona de carga o haz clic para seleccionarlo.
  5. Importar
    Haz clic en "IMPORTAR" y espera la confirmación.
💡
Tip: Asegúrate de que los nombres de clientes en el Excel coincidan exactamente con los registrados en el sistema.

💸 Control de Egresos

Administra todos los gastos operativos

📝 Registrar un Egreso

  1. Seleccionar la pestaña EGRESOS
    En el dashboard principal, cambia a la pestaña "EGRESOS".
  2. Completar la Fecha
    La fecha actual se carga automáticamente.
  3. Ingresar el Importe
    Escribe el monto del gasto en el campo "IMPORTE ($)".
  4. Seleccionar Categoría
    Elige la categoría que mejor describa el gasto (Salarios, Alquiler, Servicios, Compras, etc.).
  5. Agregar Descripción
    Detalla el concepto del gasto en el campo "DESCRIPCIÓN".
  6. Seleccionar Método de Pago
    Indica cómo se realizó el pago del egreso.
  7. Guardar el Egreso
    Haz clic en "💸 REGISTRAR EGRESO".

👥 Gestión de Clientes

Administra tu base de datos de clientes

👤 Vista de Clientes

El módulo de clientes te permite visualizar, buscar, crear y editar información de todos tus clientes.

🔍 Buscar Clientes

  1. Acceder al módulo
    Haz clic en "👥 CLIENTES" en la barra de navegación superior.
  2. Usar el buscador
    Escribe el nombre o teléfono del cliente en la barra de búsqueda.
  3. Ver resultados
    Los resultados se filtran automáticamente mientras escribes.

➕ Agregar Nuevo Cliente

  1. Hacer clic en "NUEVO CLIENTE"
    Se abrirá un formulario modal.
  2. Completar los datos
    Ingresa: Nombre completo, Teléfono (con código de área), Email (opcional).
  3. Guardar
    Haz clic en "GUARDAR CLIENTE".
✅
Automático: Los nuevos clientes comienzan con deuda $0 y 0 Ardyn Coins.

✏️ Editar Cliente

  1. Localizar el cliente
    Busca el cliente que deseas editar.
  2. Hacer clic en "EDITAR"
    Se abrirá el formulario con los datos actuales.
  3. Modificar información
    Actualiza los campos necesarios.
  4. Guardar cambios
    Haz clic en "GUARDAR CAMBIOS".

📊 Información Visible de Cada Cliente

  • Nombre: Nombre completo del cliente
  • Teléfono: Número de contacto (usado para notificaciones de WhatsApp)
  • Deuda: Saldo pendiente en cuenta corriente (en rojo si tiene deuda)
  • Ardyn Coins: Puntos acumulados en el programa de fidelización
⚠️
Importante: No puedes eliminar clientes que tengan transacciones registradas. Primero debes resolver sus cuentas.

💳 Cuenta Corriente

Gestiona créditos y pagos de clientes

💰 Sistema de Cuenta Corriente

El módulo de Cuenta Corriente permite gestionar las compras a crédito y los pagos de tus clientes, con notificaciones automáticas por WhatsApp.

📝 Registrar una Compra en Cuenta Corriente

  1. Acceder al módulo
    Haz clic en "💳 CTA CTE" en la navegación superior.
  2. Buscar y seleccionar cliente
    Escribe el nombre o teléfono del cliente en el campo de búsqueda y selecciónalo.
  3. Ingresar el importe
    Escribe el monto de la compra.
  4. Seleccionar "COMPRA EN CUENTA CORRIENTE"
    Haz clic en el botón rojo de "COMPRA EN CUENTA CORRIENTE".
  5. Verificar el balance
    El sistema mostrará una vista previa del balance actual y el nuevo balance después de la transacción.
  6. Confirmar
    Haz clic en "📝 REGISTRAR COMPRA".
✅
Notificación Automática: El cliente recibirá un mensaje de WhatsApp con el detalle de la compra y su nuevo saldo.

💵 Registrar un Pago

  1. Seleccionar cliente
    Busca y selecciona el cliente que realizará el pago.
  2. Ingresar el monto del pago
    Escribe cuánto está pagando el cliente.
  3. Seleccionar "PAGO"
    Haz clic en el botón verde de "PAGO".
  4. Verificar el nuevo balance
    Revisa que el cálculo sea correcto en la vista previa.
  5. Confirmar
    Haz clic en "💰 REGISTRAR PAGO".
💡
Tip: Puedes registrar pagos parciales. El sistema actualizará el saldo automáticamente.

📊 Historial de Movimientos

En la parte inferior del módulo verás todos los movimientos del mes en curso:

  • Fecha: Cuándo se realizó la transacción
  • Cliente: Nombre del cliente
  • Tipo: COMPRA (rojo) o PAGO (verde)
  • Importe: Monto de la transacción
  • Balance: Saldo después de la transacción
⚠️
Importante: El historial muestra solo los movimientos del mes actual. Para ver históricos completos, usa el módulo de Analytics.

🪙 Ardyn Coins

Programa de fidelización y recompensas

🎁 Sistema de Puntos Ardyn Coins

Ardyn Coins es un programa de fidelización que permite premiar a tus clientes más frecuentes con puntos canjeables.

➕ Agregar Coins a un Cliente

  1. Acceder al módulo
    Haz clic en "🪙 ARDYN COINS" en la navegación superior.
  2. Buscar cliente
    Escribe el nombre o teléfono del cliente y selecciónalo.
  3. Ingresar cantidad de coins
    Escribe cuántos coins deseas agregar.
  4. Seleccionar "AGREGAR COINS"
    Haz clic en el botón verde.
  5. Confirmar
    Haz clic en "➕ AGREGAR COINS".

➖ Descontar Coins (Canje)

  1. Seleccionar cliente
    Busca al cliente que desea canjear sus coins.
  2. Ingresar cantidad a descontar
    Escribe cuántos coins va a canjear.
  3. Seleccionar "DESCONTAR COINS"
    Haz clic en el botón rojo.
  4. Verificar saldo
    Asegúrate de que el cliente tenga suficientes coins.
  5. Confirmar
    Haz clic en "➖ DESCONTAR COINS".
✅
Notificación: El cliente recibirá un mensaje de WhatsApp informando sobre el movimiento de coins.

❓ Preguntas Frecuentes

¿Puedo editar una transacción después de guardarla?

Sí, en el historial reciente puedes hacer clic en el ícono de editar para modificar cualquier transacción. Los cambios se reflejarán inmediatamente.

¿Cómo elimino una transacción incorrecta?

En el historial, cada transacción tiene un botón de eliminar (🗑️). Haz clic y confirma la eliminación. Esta acción no se puede deshacer.

¿Las notificaciones de WhatsApp se envían automáticamente?

Sí, cuando registras una compra en cuenta corriente o un movimiento de Ardyn Coins, el sistema envía automáticamente una notificación al cliente si tiene un número de teléfono válido registrado.

¿Puedo usar el sistema desde mi celular?

Sí, Ardyn Labs es completamente responsive y funciona perfectamente en dispositivos móviles. Simplemente accede desde el navegador de tu teléfono.

¿Cómo recupero datos si borro algo por error?

El sistema mantiene un registro de todas las transacciones. Si eliminas algo por error, contacta al administrador del sistema para recuperarlo desde la base de datos.

¿Puedo personalizar las categorías de egresos?

Las categorías están predefinidas para mantener consistencia en los reportes. Si necesitas una categoría adicional, contacta al administrador del sistema.
