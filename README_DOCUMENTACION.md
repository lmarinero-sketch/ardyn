### 2. Tutorial Interactivo
**Archivo:** `TUTORIAL_INTERACTIVO.html`

Tutorial paso a paso con guías visuales interactivas:

**Tutoriales Incluidos:**
1. 🚀 **Primeros Pasos** (5 min, 6 pasos)
   - Navegación básica del sistema
   - Conocer el dashboard principal

2. 💰 **Registrar Ventas** (7 min, 8 pasos)
   - Cómo registrar una venta completa
   - Selección de clientes y métodos de pago

3. 👥 **Gestión de Clientes** (6 min, 7 pasos)
   - Crear, editar y buscar clientes
   - Administrar la base de datos

4. 💳 **Cuenta Corriente** (8 min, 9 pasos)
   - Registrar compras a crédito
   - Gestionar pagos de clientes

5. 🪙 **Ardyn Coins** (5 min, 6 pasos)
   - Programa de fidelización
   - Agregar y canjear puntos

6. 📊 **Analytics** (10 min, 10 pasos)
   - Análisis de datos
   - Generación de reportes

**Características:**
- ✨ Interfaz interactiva y animada
- 📊 Barra de progreso visual
- ⌨️ Navegación con teclado (flechas)
- 🎯 Pasos claros y concisos
- 🎨 Diseño moderno con animaciones
- 📱 Responsive

**Cómo usar:**
1. Abre `TUTORIAL_INTERACTIVO.html` en tu navegador
2. Selecciona el tutorial que deseas realizar
3. Sigue los pasos uno por uno
4. Usa los botones "Siguiente" y "Anterior" o las flechas del teclado

## 🎯 Módulos del Sistema

### Panel Operativo
- **Ventas**: Registro de ingresos con múltiples métodos de pago
- **Egresos**: Control de gastos por categorías
- **Importación**: Carga masiva desde Excel

### Gestión de Clientes
- **Base de Datos**: Información completa de clientes
- **Búsqueda**: Filtrado rápido por nombre o teléfono
- **Edición**: Actualización de datos en tiempo real

### Cuenta Corriente
- **Créditos**: Registro de compras a cuenta
- **Pagos**: Gestión de cobros y saldos
- **Notificaciones**: WhatsApp automático

### Ardyn Coins
- **Fidelización**: Sistema de puntos
- **Canjes**: Descuentos y recompensas
- **Historial**: Seguimiento de movimientos

### Business Intelligence
- **KPIs**: Métricas clave del negocio
- **Gráficos**: Visualización de tendencias
- **Reportes**: Exportación en PDF/Excel/CSV
